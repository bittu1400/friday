# G11 — Proactive Friday Implementation Plan

**Goal:** Give Friday proactivity (reminders, timers, startup/sign-off briefings, conversational DND, desktop notifications) without violating FR-5 (one turn in flight) via a single turn queue and SQLite persistence.

**Spec:** `docs/superpowers/specs/2026-08-24-phase2-design.md` (§3 G11; ADR-056).

## Constraints
- **#5 One turn in flight:** Proactive events enter the single turn queue; executed only when idle.
- **#7 No raw transcripts to disk:** Reminders store user-requested task/message data only.
- **#9 / #4 Execute first, then speak:** Reminders and briefings execute then speak via outcome templates.
- **#10 Reversibility:** Reminders can be cancelled by voice or CLI.

---

## Tasks

### Task 1: Reminder Store (`friday/store/reminders.py`, `tests/test_reminders.py`)
- SQLite table `reminders` (`id TEXT PRIMARY KEY, created_at REAL, fire_at REAL, kind TEXT, message TEXT, state TEXT`).
- Schema migration in `friday/store/db.py`.
- Methods: `add_reminder(db, seconds, message, kind="timer") -> str`, `get_due_reminders(db, now) -> list[Reminder]`, `mark_fired(db, reminder_id)`, `list_active(db) -> list[Reminder]`, `cancel_reminder(db, reminder_id) -> bool`.

### Task 2: Action Schema & Tool for Reminders (`friday/llm/schema.py`, `friday/turn.py`)
- Add `set_reminder` (params: `seconds: int`, `message: str`) to closed action enum.
- Add `cancel_reminder` (params: `reminder_id: str`) / `list_reminders`.
- Update `plan.gbnf` via schema generator.
- Integrate tool execution in `turn.py` (stores in `reminders` table, returns spoken confirmation template).

### Task 3: Conversational DND, Notifier & Briefings (`friday/proactive/`)
- `friday/proactive/notifier.py`: non-blocking `notify-send` wrapper.
- `friday/proactive/dnd.py`: Conversational DND state manager (`is_dnd`, `set_dnd`, `clear_dnd`, hush phrase check).
- `friday/proactive/briefing.py`: `generate_startup_briefing(db)` and `generate_signoff_summary(dialogue, client)`.

### Task 4: Scheduler & Single Turn Arbiter (`friday/proactive/scheduler.py`)
- Scheduler background task polling due reminders every 1.0s.
- When reminder fires: pushes proactive event to daemon queue.
- If daemon is idle: triggers delivery (speaks "Reminder: <message>" + `notify-send`).
- User-set reminders fire during DND (ADR-056 user decision). Spontaneous suggestions/briefings respect DND.

### Task 5: Integration into Daemon (`friday/daemon.py`, `friday/voice_main.py`)
- Wire scheduler, DND check on user inputs (clears DND when user speaks), startup briefing trigger, and signoff phrase detection ("goodnight", "bye") into `Daemon`.
- Tests in `tests/test_reminders.py`, `tests/test_proactive.py`, and `tests/test_daemon.py`.
