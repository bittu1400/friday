# G10 — Wake Word + AEC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Friday activate hands-free on the spoken phrase "hey jarvis", without the PTT key, while its own TTS never self-triggers it and the user can interrupt (barge-in) by speaking.

**Architecture:** A background `WakeListener` owns an always-on 16 kHz mic stream, independent of the turn FSM. Each frame passes through an acoustic-echo-cancellation (AEC) stage (far-end reference = Friday's TTS playback), then a wake-word detector (openWakeWord `hey_jarvis`) and a voice-activity detector (VAD). When idle, a wake hit tells the daemon to begin a capture; a VAD end-of-speech tells it to end the capture (there is no key release in hands-free). While speaking, sustained VAD speech triggers barge-in. The existing PTT path is untouched and remains the fallback. Nothing is written to disk.

**Tech Stack:** Python 3.12, `uv`, asyncio, `sounddevice`/PortAudio, `numpy`, openWakeWord (CPU/ONNX), an AEC library (chosen in Task 1), a VAD library (chosen in Task 3). CPU only — no CUDA, no torch.

**Spec:** `docs/superpowers/specs/2026-08-24-phase2-design.md` (§2 G10; ADR-055). Read it alongside this plan.

## Global Constraints

Copied verbatim from the Phase 1 invariants and the spec — every task's requirements implicitly include these:

- **#6 CPU only.** Only llama-server touches CUDA. STT, TTS, wake, AEC, VAD are all CPU. Before installing any dependency, `uv pip install --dry-run <pkg>`; if it drags torch/CUDA, it is disqualified (ADR-018, ADR-039/041 drill).
- **#7 No disk.** Raw audio, transcripts, and the rolling buffer live in RAM only — never written to disk.
- **#8 Loopback only.** No new network bind. The wake path touches no network at all.
- **#5 One turn in flight.** A wake hit or barge-in is only honored per the FSM's existing rules (begin only from IDLE; barge-in only from SPEAKING). It is never queued.
- **#9 / #4.** The 15 s capture cap (`MAX_CAPTURE_S`) still bounds every capture, wake-initiated ones included.
- **PTT stays.** The `toggle`/`press`/`release` path (ADR-044) is not modified; it remains the reliable fallback.
- **Fail-soft.** Missing model, library, or device disables the wake path and logs a warning — the daemon still answers PTT. Same discipline as `capture.py`/`tts.py`.
- **Style.** Type hints on public functions, `frozen=True` dataclasses by default, errors via the taxonomy (never speak/log a raw exception), comments explain *why*.

## Task 6: WakeListener orchestrator (`friday/audio/wake.py`)

Owns the always-on stream and wires AEC→wake+VAD. The **orchestration logic is TDD'd with fakes**; the real InputStream is fail-soft glue (same pattern as `capture.py`).

**Files:**
- Create: `friday/audio/wake.py`
- Test: `tests/test_wake.py`

**Interfaces:**
- Consumes: `AecProcessor` (Task 4), `Vad`/`SpeechGate` (Task 5), `WakeDetector` (below).
- Produces:
  - `class WakeDetector` with `def score(self, frame: np.ndarray) -> float` + `create(model_path, *, threshold) -> WakeDetector | None` (openWakeWord glue from ADR-061), fail-soft.
  - `class WakeCallbacks` — a `frozen=True` dataclass of three **synchronous** `Callable[[], None]`: `on_wake`, `on_speech_end`, `on_barge`. (Sync on purpose: the audio thread cannot `await`. `voice_main` builds these to wrap the daemon's async handlers via `asyncio.run_coroutine_threadsafe(daemon.on_wake(), loop)`; tests pass plain collectors.)
  - `class WakeListener`:
    - `__init__(self, *, detector, vad, aec, callbacks: WakeCallbacks, far_ref: FarEndRef, threshold, frame_len, refractory_s, is_idle, is_speaking, schedule: Callable[[Callable[[], None]], None] = _run_now)` where `is_idle`/`is_speaking` are `Callable[[], bool]` reading the daemon FSM, and `schedule` marshals a callback off the audio thread (real default wraps `loop.call_soon_threadsafe`; tests inject `lambda cb: cb()` to run inline). `_run_now` is a module-level `lambda cb: cb()`.
    - `def _on_frame(self, frame: np.ndarray) -> None` — the pure per-frame router, called from the audio thread; it AEC-cleans (`far_ref.read(len)` supplies the far-end), then routes on an internal `_awaiting_end` flag + the FSM predicates:
      - **idle and not `_awaiting_end`** ⇒ wake score ≥ threshold (and past refractory) does `schedule(callbacks.on_wake)` and sets `_awaiting_end = True`.
      - **`_awaiting_end`** (a wake we started is now being spoken to) ⇒ feed the capture `SpeechGate`; on its `"end"`, do `schedule(callbacks.on_speech_end)` and clear `_awaiting_end`. This is why a PTT-initiated capture is untouched: the listener only tracks end-of-speech for a capture *it* woke, never one PTT began (when PTT starts a capture, `is_idle` is already False, so the wake branch never armed `_awaiting_end`).
      - **speaking** ⇒ feed the barge `SpeechGate`; on `"start"`, do `schedule(callbacks.on_barge)`.
      - otherwise ⇒ do nothing.
    - `def start(self) -> bool` / `def stop(self) -> None` — open/close the InputStream (fail-soft ⇒ `start` returns False, daemon logs "no wake: PTT only").
  - `class FarEndRef` — a small lock-free ring the `Speaker` writes played PCM into and `_on_frame` reads aligned frames from; `read(n)` returns `None` when nothing is playing.

- [x] **Step 1: Write failing tests** for `_on_frame` routing with fakes (no audio, no libraries):

```python
import numpy as np
from friday.audio.aec import NullAec
from friday.audio.wake import WakeListener, WakeCallbacks, FarEndRef

class FakeDetector:
    def __init__(self, score): self._s = score
    def score(self, frame): return self._s

class FakeVad:
    def __init__(self, voiced): self._v = voiced
    def is_speech(self, frame): return self._v

def make(*, score, voiced, idle, speaking, calls):
    return WakeListener(
        detector=FakeDetector(score), vad=FakeVad(voiced), aec=NullAec(),
        callbacks=calls, far_ref=FarEndRef(), threshold=0.5,
        frame_len=320, refractory_s=1.5,
        is_idle=lambda: idle, is_speaking=lambda: speaking,
        schedule=lambda cb: cb(),   # run inline — no loop, no threads in the test
    )

def _frame():
    return np.zeros(320, dtype=np.float32)

def test_wake_hit_when_idle_fires_on_wake():
    fired = []
    calls = WakeCallbacks(on_wake=lambda: fired.append("wake"),
                          on_speech_end=lambda: None, on_barge=lambda: None)
    wl = make(score=0.9, voiced=False, idle=True, speaking=False, calls=calls)
    wl._on_frame(_frame())
    assert fired == ["wake"]

def test_no_wake_when_below_threshold():
    fired = []
    calls = WakeCallbacks(on_wake=lambda: fired.append("wake"),
                          on_speech_end=lambda: None, on_barge=lambda: None)
    wl = make(score=0.2, voiced=False, idle=True, speaking=False, calls=calls)
    wl._on_frame(_frame())
    assert fired == []

def test_speech_during_speaking_fires_barge():
    fired = []
    calls = WakeCallbacks(on_wake=lambda: None, on_speech_end=lambda: None,
                          on_barge=lambda: fired.append("barge"))
    wl = make(score=0.0, voiced=True, idle=False, speaking=True, calls=calls)
    for _ in range(20):  # exceed min_speech_s
        wl._on_frame(_frame())
    assert "barge" in fired

def test_refractory_suppresses_second_wake():
    fired = []
    calls = WakeCallbacks(on_wake=lambda: fired.append("wake"),
                          on_speech_end=lambda: None, on_barge=lambda: None)
    wl = make(score=0.9, voiced=False, idle=True, speaking=False, calls=calls)
    wl._on_frame(_frame())
    wl._on_frame(_frame())  # immediately again, inside refractory
    assert fired == ["wake"]  # second hit ignored
```

**Framing note (avoids a size mismatch):** the three libraries want different block sizes — AEC ~10 ms (`AEC_FRAME_MS`, 160 samples), VAD/wake ~20 ms (`WAKE_FRAME_MS`, 320 samples), and openWakeWord accumulates its own ~80 ms window internally. The listener's `frame_len` is the base VAD/wake frame (320); each adapter **reframes internally to its library's required block** (`AecProcessor.process` and `WakeDetector.score` buffer/re-slice as needed). So `frame_len` need not equal `AEC_FRAME_MS` — the public `process(near, far)` / `score(frame)` calls stay frame-agnostic to the caller, and the `NullAec`/fake paths in the unit tests pass any length through untouched.
